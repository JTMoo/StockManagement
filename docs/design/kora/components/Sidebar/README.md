The single navigation surface, left-aligned, `surface-raised` on `surface-page`, `border` on its right edge - replaces a right-hand menu, and there is no second one. Fixed width `4 × space-7` (192px) expanded, icon-only collapsed (a user preference, not a breakpoint - it stays expanded until they collapse it).

Top to bottom: the single most-repeated action of the day as its own pinned row above a divider ("Venta rápida", `brand-strong` text so it reads as different from the list below); a search field (opens the same `CommandPalette` a keyboard user reaches with `Ctrl`/`Cmd`+K); then sections in `control`/`ink-faint` uppercase labels grouping items by how often staff touch them - daily use first (Ventas, Facturas, Stock), occasional next (Clientes, Proveedores), rare pinned to the bottom (Importar, Usuarios, Config). Nine top-level items at most, no nested/expandable sub-menus and no "More" overflow - if a tenth screen is needed, merge two existing ones or promote it into the command palette only.

An item is `body-strong`/`ink-muted` at rest, `ink` + `surface-sunken` on hover, and `brand-strong` text on a `brand-subtle` pill (`radius-md`) when its screen is open - the one place `brand` colors something other than the primary button, because "where am I" is exactly the information this component exists to carry.
