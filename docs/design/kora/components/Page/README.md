Every screen, list or form: `display` title flush left, one toolbar of at most three actions flush right on the same row, content below at `space-5` gap. The toolbar's rightmost, most-emphasized button is this screen's one primary action - never more than one `Button.primary` per `Page`. No breadcrumb, no back arrow: the `Sidebar` is always visible, so "back" is just clicking the item you were already on. Max content width `72rem`, so a wide monitor doesn't stretch a form across the whole screen.
