**Intentional addition** - the current app has no transient feedback at all; every save waits for a full page response. A confirmation for a routine, reversible action ("Factura guardada", "Producto agregado") that needs no click to dismiss - `surface-raised`, `border`, `radius-md`, bottom-right, auto-dismisses after 4s or on click, `success`/`danger`/`info` left icon matching the outcome. It replaces a blocking "OK" dialog for anything that isn't itself a confirm step; a destructive action still gets its own confirm, never a toast.
