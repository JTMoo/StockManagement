A closed set of 2-3 mutually exclusive options shown as one bordered row, not a dropdown - for a choice made on nearly every use of a form (Contado/Crédito on a sale, Compra/Venta on a movement). `border` around the group, `radius-md` on the outer corners only, the selected option `on-fill` text on a `brand` fill, the rest `ink-muted` on `surface-raised`. Never more than three options - past that, use a real `select`.
