A word plus a small filled dot, never a color alone - `success`/`success-subtle`, `warning`/`warning-subtle`, `danger`/`danger-subtle` or `info`/`info-subtle`, `radius-sm`, `control` size but regular weight. `success` reads as safe under red-green color blindness because it's pulled toward blue-green rather than a pure green; keep that hue when adding a status, don't tint it back toward green for "brand consistency".

Stock: `Agotado` (danger), `Por agotarse` (warning, at or below the reorder level), `En stock` (success). Invoices: `Borrador` (info), `Pendiente` (warning), `Pagada` (success), `Vencida` (danger), `Anulada` (a plain `border`/`ink-faint` badge - it's not a live state to act on). Import rows: `Importado` (success), `Duplicado` (warning), `Error` (danger) - each keeps the source row reference (archivo, hoja, fila) beside it, not just the badge.
